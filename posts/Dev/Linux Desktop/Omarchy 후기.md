### 기존의 Linux Desktop 사용 경험
원래는 Desktop에 Ubuntu와 Windows 를 Duel booting Setting을 통해서 사용해왔다.
Ubuntu 24.04 부터 25.10 까지 쓰다가 새로운 경험을 하고 싶어 Debian 13으로 넘어왔고 지금까지 사용중이다.
Arch 도 써볼까 생각은 해봤지만 업데이트 지옥이란 말에 우선 보류를 해놓고 USB 에 OS를 깔아 보는 정도로 해봤다.

### 당근
Linux desktop을 구형 노트북에서 써보고 싶었다. ~~어느 영상인진 잘 기억 안나는데, minecraft 용 git을 만들었다고 어그로 끈? 영상에서~~ Linux 이기 때문에 노트북을 오래 썼다는 말이 기억에 남았던 것 같다.
당근에 인텔 10세대 16gb thinkpad laptop을 팔기에 사왔고, 뭔가 인터넷에서 omarchy를 많이 들어본 것 같아 써보기로 결정했다.

### 설치 & 세팅
쉬웠다. 세팅 할게 없는 느낌이었다.

Obsidian, Localsend, Discord, Chromium, Firefox, Zed 모두 List 에 등록되어 있었고 난 Enter 와 Password만 입력하면 끝났다. 되게 신기한 경험이었다.

그 외의 것들, Hyprland, Battery Limit, Keyd, 한글, 터치패드 스크롤 방향 수정 등 대부분 Codex 가 세팅했고 난 실행만 하면 됐기 때문에 문제가 없었다.
AI 이후로 사용 난이도가 확 내려간게 맞는 것 같다.

### 경험
맥에서 Spotlight 같이 검색 창을 통해 앱 실행하는 방식을 선호하는데, 해당 기능을 Super + Space 로 비슷하게 지원하는 점이 맘에 들었다.

그리고 Tiling Window는 약간 불편한 면이 있다면 창을 여러개 띄울 때 하나씩 floating 으로 바꿔줘야 하는 불편함이 있다.

Workspace 로 분리해 이동하는 환경이 작은 화면에서 이동하기에는 되게 좋다.(super+num)

익숙해지기까지 좀 시간이 걸리고 세팅 경험과 반대로 사용은 어렵다
