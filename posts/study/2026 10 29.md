### Keycloak
산돌이 프로젝트 보면서 이해가 안되는게 Keycloak 이라 판단. Keycloak 동작 부터 정리해보기로 함

###### Realm, Client, User, Roles 관계
Client -> 연결 대상 (서버)
User -> 계정
Realm 은 이 둘을 소유함.

Client <-> User 는 관계 x

Client Role, Realm Role 은 각각 관리되고 User 가 가질 수 있음

JWT 구조
```
{
  "sub": "bob-user-uuid",
  "azp": "react-web",
  "realm_access": {
    "roles": [
      "TEAM_USER",
      "TEAM_ADMIN"
    ]
  },
  "resource_access": {
    "nest-api": {
      "roles": [
        "reports.read",
        "reports.write"
      ]
    }
  }
}
```

###### 오해
Client 가 User 소유하는 줄 (Realm -> Client -> User -> Role)
