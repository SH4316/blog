I5 10세대 Thinkpad 중고로 구매후 Omarchy 깔아서 써보는 중 입니다.

간단 후기 정리해보자면
1. 제가 쓰는 앱은 모두 리스트에 등록 되어 있어서 단순히 "검색 -> 실행 -> 설치" 과정이 매끄럽고, 직접 설치한다는 느낌보단 설치되어 있는 느낌이 강합니다. 
2. 페이지별로 세팅해두고 전환하는 느낌이 생각보다 좋았어요. alt + tab 기반으로 화면 전환보다 편해요. 
	- 다른 Desktop 에 설치된 Debian 에서도 해당 방식으로 해도 좋을 것 같아요
	- 작은 화면일 수록 더 효율적인 느낌
3. 단점으로는 여러 앱 막 띄워 두기는 불편할 것 같아요. 
	- 예를들어 obsidian setting 할 때 여러 창이 뜨는데 타일이 쪼개지면서 점점 작아져 UI 를 제대로 볼 수 없는 경우가 있었죠.
4. AI 기능은 Crash 나면 Codex 로 자동으로 연결되는 기능, 상단 바에 Codex 와 Claude 사용량 뜨는 기능은 신기했습니다. 근데 더 편한지는 모르겠어요
